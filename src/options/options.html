How to get a free DeepL API key
  1. Create an account and pick DeepL API Free: deepl.com/pro-api.
  2. Open your account page, then API keys & limits, and copy your key.
  3. Paste it above. Free keys end in :fx; the extension picks the right server for you.

The key is stored only on this device. If it ever leaks, create a new one in your DeepL account and replace it here.
